# Прозрачная вакансия (Регион 39)

Прототип для автоматического анализа вакансий Калининградской области с портала «Работа в России» (API `opendata.trudvsem.ru`). 
Сервис проверяет, насколько понятно в вакансии описаны условия работы (оплата, график, занятость, адрес, обязанности), и формирует отчет с конкретными рекомендациями для работодателя.

## Архитектура и пайплайн

Сервис написан на Python (3.13) и использует только стандартную библиотеку для работы с сетью (без лишних зависимостей для API). 
Поток данных:
1. **Загрузка (`app/loader.py`)** — читает локальный JSON (проверочный режим) или запрашивает API постранично (`offset` как номер страницы, `limit=100`).
2. **Нормализация (`normalizer.py`)** — превращает сырые JSON-словари в строгие объекты `Vacancy` (`models.py`), извлекая данные из вложенных структур (`requirement.qualification`, `addresses`, `term.text` и т.д.).
3. **Анализ правилами (`rules.py`)** — детерминированный поиск пропусков, неоднозначностей и противоречий без ИИ.
4. **Анализ ИИ (`app/ai_check.py`)** — передача текстовых и структурированных полей в LLM для поиска скрытых смыслов (TODO: реализация).
5. **Сборка отчета (`app/pipeline.py`)** — объединение замечаний, дедупликация по ID и атомарная запись в `report.json`.

**Точка входа:** `app/__main__.py` (команды `run` и `check`).
