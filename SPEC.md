# SPEC: «Прозрачная вакансия» (регион 39)

## Цель
Автоматически получать вакансии Калининградской области с портала «Работа в России»
и формировать JSON-отчёт о том, насколько понятно описаны условия работы.
Отчёт помогает редактору подготовить уточнения для работодателя.

## Режимы
- Рабочий: `python -m app run` — загрузка из API
  `http://opendata.trudvsem.ru/api/v1/vacancies/region/39`, постранично (`offset` — номер страницы, `limit=100`).
- Проверочный: `python -m app check <файл.json>` — тот же анализатор на локальном JSON в формате ответа API.
- Расписание и ручной запуск: `.github/workflows/run_bot.yml` (cron + workflow_dispatch).

## Что проверяется
Название должности, обязанности, требования, оплата, график, место работы, тип занятости.
Учитываются и описание, и структурированные поля API. Если поле содержит конкретные сведения,
их отсутствие в описании не считается проблемой.

Виды замечаний:
- Пропуск: нужных сведений нет нигде в вакансии.
- Неоднозначность: формулировка без конкретики (например, «гибкий график» без дней и смен).
- Противоречие: в двух местах разные значения одного параметра.

## Состав
- `app/fetcher.py`, `app/loader.py` — загрузка из API или файла, повторы запросов.
- `normalizer.py`, `models.py` — приведение сырого JSON к объекту `Vacancy`.
- `rules.py` — проверки без ИИ.
- `app/ai_check.py` — проверки через локальную модель (Ollama, `qwen2.5:7b`).
- `app/pipeline.py`, `app/report.py` — объединение результатов, дедупликация, запись отчёта.
- `app/__main__.py` — команды `run` и `check`.

## Формат замечания
`topic`, `field`, `quote`, `problem`, `recommendation`, `source` (`rule` или `ai`).
- Пропуск: `quote` пустая, `problem` объясняет, каких сведений не хватает.
- Противоречие: `quote` содержит оба исходных значения через ` / `.

## Формат отчёта
JSON-массив, один объект на вакансию: `{id, url, issues: []}`.
Нет замечаний — пустой массив. Один объект на ID вакансии.

## Правила работы
- Не выдумывать факты, цитаты ИИ проверяются на дословное присутствие в данных вакансии.
- Не делать выводов о нарушении закона.
- Рекомендация подсказывает, что именно уточнить.
- Повторный запуск на неизменных данных даёт тот же результат (температура ИИ 0, фиксированный seed).
- При недоступности API: сообщение об ошибке и сохранение последнего успешного отчёта.
- Ключи (если нужны) только в переменных окружения или GitHub Secrets, не в репозитории.

## Настройки
URL источника, максимум вакансий, число страниц, модель ИИ, режим ИИ — переменные окружения
(`SOURCE_URL`, `MAX_VACANCIES`, `MAX_PAGES`, `AI_MODEL`, `AI_ENABLED`), см. README.

## Вне рамок MVP
